# Security Reviews

Date-prefixed records of substantive security audits, linked from
[`../security/audit-history.md`](../security/audit-history.md).

The audit-history page holds the chronological summary; this directory
holds the long-form review documents when they exist. Most entries in
audit-history are self-contained — only audits whose findings need more
space (cross-system reviews, third-party reports) get a file here.

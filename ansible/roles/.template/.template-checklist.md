# Creating a New Ansible Role from Template

## Quick Steps

1. **Copy the template**:
   ```bash
   cp -r ansible/roles/.template ansible/roles/my_new_role
   ```

   Or use the generator script:
   ```bash
   make new-role ROLE=my_new_role
   ```

2. **Replace placeholders**:
   - Find all `[ROLE_NAME]` strings in files
   - Replace with your actual role name
   - Files with placeholders: `meta/main.yml`, `README.md`, `molecule/*.yml`

3. **Customize for your role**:
   - Edit `defaults/main.yml` — add your role's variables and defaults
   - Edit `tasks/main.yml` — implement your role's logic
   - Edit `molecule/default/converge.yml` — add pre_tasks (stubs, setup) if needed
   - Edit `molecule/default/verify.yml` — add specific assertions for your role
   - Edit `molecule/default/molecule.yml` — adjust image/values if needed

4. **Test locally**:
   ```bash
   # Run full test suite
   make test-molecule-{role_name}

   # Or directly:
   cd ansible/roles/my_new_role
   molecule test
   ```

5. **Reference existing roles**:
   - **Simple role**: `ansible/roles/tailscale/` (single scenario, basic tasks)
   - **Complex role**: `ansible/roles/k3s/` (4 scenarios, multi-mode)
   - **Check prepare.yml** in k3s or argocd for bootstrap patterns

## Key Points

- ✅ **always_required**:
  - At least one task in `tasks/main.yml`
  - At least one assertion in `verify.yml`
  - Valid YAML in all files
  - Metadata in `meta/main.yml`

- ✅ **when_using_slim_image** (debian:bookworm-slim):
  - Keep `prepare.yml` (bootstraps python3 + sudo)
  - Use `ansible_become: false` in molecule.yml inventory

- ✅ **when_switching_to_full_image** (geerlingguy/* images):
  - Remove or simplify `prepare.yml`
  - File already has python, sudo, systemd

- ❌ **do_not_do**:
  - Don't mix bootstrap logic into converge.yml
  - Don't use `become: true` with slim image before sudo installed
  - Don't forget `ansible_become: false` in docker containers

## Testing Requirements

**CI will enforce:**
- `molecule/default/molecule.yml` exists
- `molecule/default/converge.yml` exists
- `molecule/default/verify.yml` exists
- At least one task in verify.yml (verify role ran)

**Local validation:**
```bash
# Check structure
make validate-ansible-structure

# Run tests
make test-molecule-{role_name}
```

**CI validation** (on PR):
- New roles without `molecule/default/` will be REJECTED
- All required molecule files must exist
